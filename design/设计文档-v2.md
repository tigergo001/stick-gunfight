## 1. 辅助瞄准系统

三档,主菜单「辅助瞄准」分段开关,**随时可切**:

| 档位 | 行为 | 适用 |
| --- | --- | --- |
| 关 | 纯手动,准星即弹道 | 高手 |
| **辅助**(默认) | 准星朝向与敌人夹角 ≤14° 时,弹道向敌人方向修正 55%;只修正"看得见"的敌人 | 大多数玩家 |
| 锁定 | 自动锁定屏幕内最近的可见敌人,准星自动吸附其胸口;开火即朝目标 | 休闲/手残党 |

**视觉反馈**:辅助生效时准星外圈变金色;锁定时显示红色四角框 + 到目标的细虚线。
**平衡约束**:仅单人/闯关生效;联机模式强制「关」(公平性),房间创建者可在联机面板开关「本房允许辅助」。

## 2. 敌人智商重构(削弱)

现状 AI 太强。重构为 **4 档智商**,直接决定三个战斗参数:

| 智商 | 名称 | 射速倍率 | 准确度(瞄准误差) | 反应时间 | 预判走位 |
| --- | --- | --- | --- | --- | --- |
| ★ | 新兵 | ×0.50 | 很差(误差 ×2.2) | 0.6~1.2s | 无 |
| ★★ | 老兵 | ×0.75 | 一般(×1.4) | 0.4~0.8s | 弱(50%) |
| ★★★ | 精英 | ×1.00 | 较准(×1.0) | 0.2~0.5s | 有 |
| ★★★★ | 王牌 | ×1.15 | 很准(×0.6) | 0.1~0.35s | 强(130%) |

- 射速倍率直接乘在武器 RPM 上(新兵 M249 只有 330 发/分,不再弹雨)
- 名牌追加智商星标:`★★ 精英·刀锋`
- 闯关低关卡以 ★★ 为主,高关卡混入 ★★★/★★★★;单人练习沿用 弱/中/强 → 映射到 ★★/★★★/★★★★
- 品类(普通/精英/重装/狙击)与智商正交:品类决定血量与武器,智商决定打法

## 3. RPG 火箭筒 与 坦克

### RPG-7 火箭筒(玩家武器,Lv.6 解锁)
| 参数 | 数值 |
| --- | --- |
| 弹种 | 火箭弹:直线飞行 + 尾焰轨迹,中速(900/s),射程 1800 |
| 爆炸 | 半径 110 范围伤害(最远 65),**对自身同样生效**(RPG 自伤,谨慎贴脸) |
| 射速/弹药 | 1 发 / 2.5s,弹夹 1 发,装填 2.8s,无爆头 |
| 后坐力 | 全游戏最大(会把火柴人向后推一大段) |
| 克制 | 对重装兵、敌方坦克伤害 ×2;可引爆油桶产生连锁 |

UI:武器卡新增「RPG-7 Lv.6」;持有时火柴人肩扛筒状武器(趴射姿势微调)。

### 坦克(载具 + Boss 两用)
- **玩家夺取**:闯关特定关卡(第 3/6/9…关)战场停放**无人坦克**,玩家走近按 `E` 登载:
  - 坦克属性:血量 500(独立血条)、移动 240/s、**不能跳跃**、免疫普通子弹 70%(仍受 30% 减免伤害)
  - 主炮:炮弹(爆炸伤害 60/半径 100),射速 1 发/1.8s;RPG 对坦克 ×2.5
  - 坦克血量归零 → 玩家被弹出(保留自身血量),坦克残骸留存
- **敌方坦克 Boss**:每第 5 关关底镇守:
  - 血量 900,左右巡逻 + 炮击玩家,炮弹落点有预警红圈(1 秒后爆炸)
  - 弱点:**尾部油箱**(受击 ×3);击败掉落大量 XP + 补给
- 登载/跳出:`E` 上车,再按 `E` 下车

## 4. 横向卷轴闯关(类马里奥推进)

### 世界结构
- 单屏 1600×900 → **横向长卷**:每关由 3~5 个「场景段」拼接,总宽 4800~8000px
- **摄像机水平跟随玩家**(带平滑),上下仍为固定视野;左右边界钳制
- 主题分段(每关按进度切换背景/配色):
  1. 🏙 城市废墟(现 Map)
  2. 🌲 丛林哨所(密树+雾)
  3. 🏜 沙漠公路(沙丘+废车掩体)
  4. 🏰 军事基地(铁墙+闸门,关底 Boss)

### 推进式玩法(替代三波刷新)
- 敌人**沿线驻守**:进入遭遇区(屏幕右侧触发线)→ 触发警报 → 该区敌人激活,红色闸门落下封锁退路
- **清空遭遇区 → 闸门升起 → 放行右进**
- 补给箱:血包(+50)/ 弹药箱(补满弹夹),散布沿途
- 到达关卡最右端**撤离点(直升机)→ 通关**;坦克 Boss 关在关底击败 Boss 后撤离
- 顶部**关卡进度条**(马里奥式):显示玩家当前位置与遭遇区/补给/Boss 图标

### 引擎改造点
| 改造 | 说明 |
| --- | --- |
| 摄像机系统 | 全局相机 X 偏移,渲染与输入统一换算 |
| 分段地图 | 地形模板库 + 段拼接器(保证可通过性) |
| 触发区 | 遭遇战/闸门/补给的事件系统 |
| 敌人驻守 AI | 新增「驻守态」:未触发时不主动追击 |
| 小地图 | 顶部进度条 + 图标 |

### 分期(建议)
| 期 | 内容 | 预估 |
| --- | --- | --- |
| P1 | 辅助瞄准 + 敌人智商重构 | 0.5 天 |
| P2 | RPG + 爆炸物系统升级 | 0.5 天 |
| P3 | 坦克(载具 + Boss) | 1 天 |
| P4 | 横向卷轴(摄像机 + 分段地图 + 触发区 + 进度条) | 1.5~2 天 |
| P5 | 打磨:新场景美术、音效、平衡 | 0.5 天 |

> P1~P3 不改变现有单屏玩法,P4 是大版本(建议独立分支开发,避免影响当前 UAT)。
