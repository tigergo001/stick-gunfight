# 🔥 火柴人机枪大战 (Stick Gunfight)

2D 平面火柴人机枪对战网页游戏。纯前端 Canvas 实现,自带**零依赖** Node 联机服务器。

> 📖 玩家请看 **[使用手册](使用手册.md)**:操作、联机教学、FAQ 一应俱全。

- 🤖 单人练习:组队打机器人(可调敌人/队友数量与**弱/中/强三档智商**,机器人会走位、跳台、点射、换弹)
- 🌐 联机对战:WebSocket 房间制,自动平衡蓝红两队,服务器结算血量与重生
- 💀 火柴人:两段式肢体 IK 步态、持枪瞄准、死亡倒地
- 🔊 程序化音效:WebAudio 现场合成,无任何外部资源

## 快速开始

### 方式一:直接玩(单人模式)
双击打开 `index.html` 即可(无需服务器)。

### 方式二:一键脚本(推荐)
```bash
./game.sh            # 启动服务器并自动打开浏览器
./game.sh stop       # 停止
./game.sh restart    # 重启
./game.sh status     # 查看状态
```
换端口:`PORT=9090 ./game.sh start`。日志写入 `server.log`。

### 方式三:手动运行
```bash
node server.js
```
然后浏览器打开 <http://localhost:8080>:

- 点「联机对战」→ 直接「加入战斗」(默认连接本机、房间 ROOM1)
- **朋友加入**:同一局域网访问 `http://<你的IP>:8080`,输入相同房间号
- **开两个浏览器标签页**也能自己和自己对战
- 换端口:`PORT=9090 node server.js`

### 运行测试
```bash
npm test                      # 离线逻辑 40 秒模拟 + 联机服务器端到端 + 联机客户端全链路
node tests/harness.mjs        # 单独跑:游戏逻辑(含机器人三档智商断言)
node tests/test-net.mjs       # 单独跑:服务器协议
node tests/test-online-client.mjs  # 单独跑:完整游戏客户端联机全链路
```

## 玩法

- 蓝红两队死斗,击杀计入团队比分;单人模式先到 **15 杀**获胜并自动开新回合
- 持续射击枪管会过热,**散布变大**;爆头 1.7 倍伤害
- 脱战 3.5 秒自动回血;重生有 1.6 秒护盾(开火即解除)
- 平台可从下方跳上,也可作掩体挡子弹

## 联机架构

- 客户端 15Hz 上报位置,服务器转发;远程玩家做 120ms 快照插值
- 命中由**射击方**判定、**服务器**结算血量/击杀/重生,天然防作弊血量
- 远程玩家的子弹仅做视觉表现,伤害统一走服务器 `hit` 消息,不会重复扣血

## 公网联机

默认适合局域网。要跨公网,可任选:端口转发路由器、`frp`/`nps` 内网穿透、或部署到任意可运行 Node 的主机(`node server.js` 后开放对应端口)。
